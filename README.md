TWRP device tree for Amazon Fire Max 11 (sunstone)
==================================================

The Amazon Fire Max 11 is an 11" tablet released in 2023, sold as model KFSNWI.

It is the only device on the `sunstone` codename. The 64 GB and 128 GB variants differ only in storage.

Device specifications
---------------------

| Feature | Amazon Fire Max 11 |
|---|---|
| Released   | 2023 |
| SoC        | MediaTek MT8188J |
| CPU        | 2x Cortex-A78 @ 2.2 GHz + 6x Cortex-A55 @ 2.0 GHz |
| GPU        | Mali-G57 MC3 |
| RAM        | 4 GB LPDDR4X @ 3733 MT/s |
| Storage    | 64 / 128 GB eMMC 5.1 |
| Wi-Fi      | MediaTek MT7902, Wi-Fi 6, dual band |
| Bluetooth  | 5.3 + BLE |
| Software   | Fire OS 8 (Android 11), kernel 5.10 |
| Display    | 11.0" 2000x1200 IPS @ 60 Hz, Novatek NT36523B |
| Touch      | Novatek NT36523N over I2C-HID, active stylus |
| Cameras    | 8 MP rear, 8 MP front |
| Battery    | 7500 mAh |
